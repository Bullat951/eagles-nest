Eagle's Nest server install (DCS dedicated server or a hosted game)
==================================================================

Eagle's Nest adds a hook to the DCS server that controllers connect to with the Eagle's Nest
client (ATC/GCI). Nothing in your missions changes, MissionScripting.lua stays as it is, and
there is nothing to run: only files to copy. Foothold missions are detected by themselves.

INSTALL
1. Stop the DCS server.
2. Open the server's Saved Games folder: the one holding Config, Logs and Missions, e.g.
     C:\Users\<user>\Saved Games\DCS.server   or   ...\DCS.openbeta_server   or   ...\DCS
3. Copy everything inside "copy-into-saved-games" into it (merge the folders).
4. Open TCP port 10309 for controllers (PowerShell as administrator):
     New-NetFirewallRule -DisplayName "Eagles Nest" -Direction Inbound -Protocol TCP -LocalPort 10309 -Action Allow
   (A hosting provider may also need the port opened in its own panel.)
5. Start the server. Done.

The first start creates Config\DCB.lua with a random password for each side. Open it in
Notepad, give the blue password to blue controllers and the red one to red. Change them there
if you like (restart the server afterwards).

Check: Logs\dcs.log shows
     DCB (Main): hook loaded, dll __VERSION__
     DCB (Main): listening on port 10309

UPDATE
Stop the server, copy "copy-into-saved-games" again (your Config\DCB.lua is kept), start it.

UNINSTALL
Delete Mods\Services\DCB, Scripts\Hooks\DCB-hook.lua, Config\DCB.lua and the DCB folder.

GOOD TO KNOW
- Security: the connection is plain TCP (passwords and the picture are not encrypted). Limit
  the firewall rule to your controllers' addresses (add  -RemoteAddress 203.0.113.5,198.51.100.7)
  or use a VPN (Tailscale, ZeroTier, WireGuard) and do not open the port to the internet.
- Each coalition's password shows that coalition's picture only (fog of war).
- Enemy ground units show on radar only in missions dated 2012 or later (enemy_ground in
  DCB.lua); before that controllers find SAMs with pilots' RWR calls.
- Terrain data for Syria is included; other terrains are sampled once on their first mission
  (in the background) and kept in the DCB folder.
- Controller actions (text to a player, F10 marks) are rate-limited and written to dcs.log.
- Problems: search dcs.log for "DCB".
- Analytics and website export (on by default, switch off in DCB.lua) are local files in the
  DCB folder; nothing is sent anywhere. Back up DCB\analytics.key (it makes the player ids).
